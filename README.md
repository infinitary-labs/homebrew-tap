# Infinitary's Homebrew Tap

Infinitary is a calm desktop first mate that runs AI crew on your own subscriptions. It is in private alpha and requires macOS Ventura or later.

Install the Infinitary alpha with:

```sh
brew install --cask infinitary-labs/tap/infinitary@alpha
```

Upgrade it with:

```sh
brew update
brew upgrade --cask infinitary@alpha
```

If you used Firstmate 3000 on this Mac, Infinitary brings your saved work over the first time it opens.

On Linux (x64), each release on this tap's Releases page carries a package for Ubuntu (`.deb`), Fedora (`.rpm`), Arch and Omarchy (`.PKGBUILD`) and NixOS (`.nix`), an AppImage for any other Linux, and `SHA256SUMS` to check them against.
